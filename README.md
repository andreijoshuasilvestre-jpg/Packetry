# Packetry
This game is a capstone project from Pampanga State University from which the proponents are from the course of Bachelor of Science in Information Technology.

Packetry is an educational networking game inspired by Cisco Packet Tracer, but more visual and game-like. You build real working networks out of PCs, switches, and routers, and the game checks whether they actually work: packets only reach their destination if your cabling, IP addresses, and router setup are correct.

## Download and Play

1. Go to the [latest release](https://github.com/andreijoshuasilvestre-jpg/Packetry/releases/latest) and download the `.zip` file.
2. Right-click the zip and choose **Extract All**.
3. Open the extracted folder and run **Packetry.exe**.

> **Windows protected your PC?** The game isn't code-signed, so Windows may show this warning. Click **More info → Run anyway**.

**Requirements:** Windows 10 or 11 (64-bit)

## What You'll Learn

- Connecting devices with cables and how switches link PCs together
- Assigning IP addresses and subnet masks
- Using a simplified router command line (based on Cisco IOS)
- Using routers to connect different subnets
- Finding and fixing faults in a broken network
- Splitting one address block across departments (VLSM)

## Levels

| # | Level | What you do |
|---|-------|-------------|
| 1 | Device Connecting | Place a table, add PCs and a switch, and cable them together |
| 2 | IP Allocation | Give PCs addresses on the same subnet so they can talk |
| 3 | Router CLI Basics | Open a router's command line and learn its modes |
| 4 | Routers & Subnetting | Connect two different subnets with a router |
| 5 | LAN Challenge | Build a small LAN on your own, with no guide |
| 6 | Two-LAN Challenge | Connect two switched departments through a router |
| 7 | Network Troubleshooting | Find and fix the faults in a pre-built network |
| 8 | Free Build: Office LAN | Design your own office network from a blank table |
| 9 | Multi-Department Network | Scale up to three departments |
| 10 | Resilience Challenge | Build a network that survives any single cable being cut |
| 11 | VLSM: Multi-Site Network | Divide one shared address block across three sites |

## Features

- **Drag and drop devices**: place PCs, switches, and routers on tables
- **Cable connections**: choose which port each cable plugs into
- **Router command line**: type real-style commands, with Tab to auto-complete and hover cards that explain each command
- **Packet animations**: send packets and watch them travel along your cables
- **Subnet color-coding**: links are colored by subnet so mistakes stand out
- **2D network diagram**: a Packet Tracer-style view of your whole network
- **Explains itself**: hover over any button or tool to see what it does
- **Automatic saving**: your progress in each level is saved as you play

## Controls

| Action | Control |
|--------|---------|
| Move the camera | W A S D |
| Zoom | Mouse scroll wheel |
| Turn the view | Q / E |
| Rotate a selected device | On-screen rotate buttons, or hold R and scroll |
| Undo | Ctrl + Z |
| Auto-complete a router command | Tab |
| Close the router command line | Esc |
